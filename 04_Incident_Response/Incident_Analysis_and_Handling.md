# Cybersecurity Incident Analysis & Handling

## Executive Summary
Documentation on the structured methodology for detecting, containing, eradicating, and recovering from security breaches based on standard NIST/SANS frameworks[cite: 2].

## Key Concepts
- **NIST SP 800-61 Lifecycle:**
  1. *Preparation:* Tools, policies, and team readiness.
  2. *Detection & Analysis:* Identifying Indicators of Compromise (IoCs) and attack vectors[cite: 2].
  3. *Containment, Eradication & Recovery:* Isolating affected systems, mitigating root causes, and safely restoring operations[cite: 2].
  4. *Post-Incident Activity:* Lessons learned, root cause analysis, and incident report writing[cite: 2].
- **Root Cause Analysis (RCA):** Determining how an attacker breached defenses to prevent repeat incidents[cite: 2].

## Practical Takeaway
Containment speed is critical: isolating an infected system immediately upon detection stops an attack from spreading across the rest of the network.
